# Contributing to Himdex

Himdex is early. Contributions are welcome if they make the project easier to
train, evaluate, reproduce, or understand.

Good first contributions:

- add dataset registry entries with clear license notes;
- improve tests for model shapes and dataset preparation;
- add evaluation scripts;
- add efficient training options such as gradient accumulation, AMP, LoRA, or
  quantization;
- improve documentation and examples.

Please keep raw datasets, large checkpoints, and private credentials out of git.
